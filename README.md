# PingGuard: Wi-Fi Fault & Congestion Diagnostics Logger

A Python-based network monitoring and data analysis project that tracks Wi-Fi stability over time, identifies connection drops and latency spikes, and records timestamped logs for troubleshooting and trend analysis.

## Overview
* Continuously checks network availability and response latency in the background.
* Separates local Wi-Fi disconnections from upstream internet outages and heavy traffic congestion.
* Exports clean, timestamped records to a structured dataset for further statistical analysis and visualization.

## Project Goals
* Capture accurate downtime and peak-hour congestion patterns.
* Turn raw network telemetry logs into actionable insights using Python data analysis tools.
